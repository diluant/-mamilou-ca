# Mamilou — site vitrine

Site statique prêt pour GitHub Pages, sans frais d’hébergement, sans boutique en ligne et sans compilation.

## Avant la mise en ligne

1. Ouvrir `script.js` et remplir `CONTACT.email`, `CONTACT.telephone` ou `CONTACT.facebook` avec les coordonnées approuvées par Mamilou. Seuls les moyens renseignés s’affichent.
2. Vérifier avec Mamilou les noms des créations et la description des services; ils ont été rédigés à partir des photos.
3. Envoyer **le contenu** de ce dossier à la racine du dépôt GitHub `diluant/-mamilou-ca` (pas le dossier parent lui-même).
4. Dans GitHub > Settings > Pages, sélectionner `Deploy from a branch`, branche `main`, dossier `/ (root)`, puis configurer `mamilou.ca` comme domaine personnalisé.
5. Chez GoDaddy, supprimer l’enregistrement A `@` pointant vers `WebsiteBuilder Site` et modifier le CNAME `www` pour `diluant.github.io`. Conserver les 4 enregistrements A de GitHub Pages, les NS, ainsi que les enregistrements de courriel existants.
6. Activer `Enforce HTTPS` lorsqu’il est disponible.

Aucun formulaire externe n’est utilisé : les visiteurs peuvent joindre Mamilou par le moyen de contact que vous choisissez.
Les images proviennent du ZIP fourni. Les fichiers MOV associés aux Live Photos n'ont pas été intégrés afin d’alléger le site.
